# Requirements trace

Each requirement of the project specification, where it is met in the repository, and a status:

* **met** — present, and exercised by a test or a run named in the row;
* **partly** — present with the stated restriction; the restriction is the reason;
* **not met** — absent; the reason is given.

The table was filled in during the final audit of the repository, in a fresh copy of the tree with
a new virtual environment, by running the commands named and reading the code named. It is a
statement by the project about itself. Nobody outside the project has reviewed it, and "met" does
not say that a result is correct: what a result may be relied on for is in
[LIMITS.md](../LIMITS.md), and what "verified" means is in [VERIFICATION.md](VERIFICATION.md)
section 1.

Counts quoted below were read from the generated files at the time of the audit; the generated
files ([VERIFICATION_REPORT.md](VERIFICATION_REPORT.md), [../data/DATA_CARD.md](../data/DATA_CARD.md))
are the place to read the current ones.

## Rules of the project owner

| Rule | Where it is kept | Status |
|---|---|---|
| No reference value from memory or from a source that was not opened | REFERENCES.md; every `problem.json` cites work, edition, location and pages | met, as far as the audit could tell: the audit compared samples of the targets with the sources, not every target |
| No tolerance adjusted, no case dropped, no model special-cased; a failing case is quarantined with a diagnosis | one policy (`benchfea.verify.POLICY`); 64 quarantined problems and the quarantine log of the dataset | met |
| Nothing says that a result is checked, approved or certified by anyone | the wording rule of CONTRIBUTING.md; tests on the README, the records and the generated documents | met |
| Where a reference or AISC 360-22 is silent, no guess: the question is recorded and the check is reported as not checked | [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md) (120 questions). Some entries follow one stated reading instead of refusing; those are marked there and wait for the owner | partly |
| No text, table or figure of a reference in the repository; no client or project data; no personal names, e-mail addresses or private paths | the audit searched the tree for these and compared word sequences with the three supplied references; one quoted sentence was replaced by a paraphrase. The address of the repository contains the account name of its owner | met |
| The engine is written from the mechanics, not ported | THEORY.md; REFERENCES.md 1.4 | met, by the project's own statement |
